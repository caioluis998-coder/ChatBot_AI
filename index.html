Como Hospedar no GitHub Pages

Você pode hospedar este aplicativo 100% grátis no GitHub Pages em poucos minutos. Siga o passo a passo abaixo:

  1. Crie uma conta no GitHub: Acesse github.com e crie uma conta gratuita caso ainda não possua.
  2. Crie um Repositório: Clique no botão "+" no canto superior direito > New repository.
    • Dê um nome (ex: meu-clone-ia).
    • Marque como Public.
    • Marque a opção "Add a README file".
    • Clique em Create repository.
  3. Adicione o Arquivo HTML:
    • No repositório criado, clique em Add file > Create new file.
    • Nomeie o arquivo obrigatoriamente como: index.html
    • Cole todo o código deste arquivo dentro do editor.
    • Role até o final e clique em Commit changes.
  4. Ative o GitHub Pages:
    • Vá nas Settings (Configurações) do repositório.
    • No menu esquerdo, clique em Pages.
    • Em Build and deployment > Branch, escolha a branch main (ou master) e a pasta /(root).
    • Clique em Save.
  5. Acesse o seu Chatbot: Em 1 a 2 minutos, o GitHub disponibilizará seu link público (ex: https://seu-usuario.github.io/meu-clone-ia/).
Privacidade Garantida: A chave da API nunca fica gravada no código do arquivo. Cada usuário que acessar o site colocará sua própria chave no painel local.
