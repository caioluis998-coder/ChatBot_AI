## 🚀 Como Clonar e Testar Localmente

Siga os passos abaixo para rodar o projeto na sua máquina e testar as alterações antes de enviar para o GitHub Pages.

### Pró-requisitos
* Um navegador web atualizado (Google Chrome, Edge, Firefox ou Safari).
* Uma chave de API do Gemini (obtenha gratuitamente no [Google AI Studio](https://aistudio.google.com/)).
* Git instalado no seu computador (opcional, você também pode baixar o ZIP).

---

### 1. Clonar o Repositório

Abra o seu terminal (Prompt de Comando, PowerShell ou Terminal do Linux/Mac) e execute:

```bash
git clone [https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git](https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git)

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias web:

* **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML)**: Estruturação semântica e acessível do chat e das janelas modais.
* **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) & [Tailwind CSS](https://tailwindcss.com/)**: Estilização moderna, layout responsivo e suporte nativo a temas (claro/escuro).
* **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)**: Lógica do aplicativo, manipulação do DOM e requisições assíncronas (`fetch`).
* **[Google Gemini API](https://ai.google.dev/)**: Modelo de inteligência artificial responsável pelo processamento de linguagem natural e geração das respostas do clone.
* **[Marked.js](https://marked.js.org/)**: Biblioteca para conversão de texto formatado em Markdown nas mensagens.
* **[FontAwesome](https://fontawesome.com/)**: Ícones vetoriais para os botões e elementos visuais da interface.
* **[LocalStorage API](https://developer.mozilla.org/pt-BR/docs/Web/API/Window/localStorage)**: Armazenamento local e seguro das configurações da API Key e do histórico no próprio navegador do usuário.
* **[GitHub Pages](https://pages.github.com/)**: Plataforma utilizada para a hospedagem gratuita e implantação (*deploy*) do projeto.
